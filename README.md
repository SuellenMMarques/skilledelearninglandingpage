# 💻 Skilled e-learning landing page

Projeto desenvolvido a partir de um desafio da plataforma Frontend Mentor, com o objetivo de praticar HTML, CSS e responsividade na construção de uma landing page moderna.

---

## 📌 Visão geral

Este projeto consiste em uma landing page para uma plataforma fictícia de cursos online, com foco em:

* Layout responsivo (mobile, tablet e desktop)
* Organização de conteúdo em grid
* Uso de variáveis CSS
* Aplicação de boas práticas de estrutura HTML

---

## 🚀 Tecnologias utilizadas

* HTML5
* CSS3
* Flexbox
* CSS Grid

---

## 🎯 Funcionalidades

* Layout adaptável para diferentes tamanhos de tela
* Seção de cursos organizada em grid responsivo
* Botões com estados de hover
* Imagem hero com comportamento adaptado para telas maiores

---

## 📱 Responsividade

O projeto foi desenvolvido utilizando a abordagem **mobile first**, com ajustes para:

* 📱 Mobile
* 📲 Tablet
* 💻 Desktop
